\vspace{0.35em}
\noindent\textbf{Robotic materials need local states that can be changed briefly and then held without continuous power. \fluxcell{} is a source-bounded design for a Sarrus-compatible cell that uses a fixed electropermanent-magnetic cartridge and moving steel keepers to make geometry, magnetic overlap, and mechanical state testable in one bench experiment. The present contribution is a locked architecture and proof protocol, not a completed actuator dataset. Force, current, heat, release, repeatability, and cycle-life claims remain unmade until the one-axis proof is built and measured.}

\section{Introduction}

Soft robots and robotic materials increasingly distribute function through body geometry, material state, and embedded physical computation rather than through a single remote actuator \cite{rus2015,wehner2016,byun2024,wang2026}. This direction is attractive because mechanical structure can store information, route signals, and shape motion before software has to intervene. The unresolved engineering question is how to make a small unit that can change state, hold that state with negligible standby power, and tile into larger visible machines without requiring a new actuator design for every morphology.

Electropermanent magnets offer a direct route to low-standby-power state retention. An \epm{} combines magnetic materials with different coercivities so that a short current pulse can switch the net external field while the magnetized state persists after current returns to zero \cite{knaian2010,johnson2024,zhu2019}. EPMs have been used for programmable matter, modular robotic connection, magnetic soft-robot components, and magnetorheological fluid control \cite{knaian2010,zhu2019,johnson2024,ntella2023}. In parallel, physical-interface work has shown that embedded magnets can create legible, passive haptic states in digitally fabricated mechanisms \cite{zheng2019}.

\fluxcell{} connects those threads to a Sarrus-cell robotic-matter concept. The design does not ask a small magnet to pull a compliant mechanism across a large open gap. Instead, a fixed \epm{} cartridge creates a localized magnetic circuit, while steel fork and tongue keepers slide through that circuit as the Sarrus-compatible frame changes width. This turns the first experiment into a compact overlap problem: pulse the cartridge, observe whether the geometry changes, check whether the state holds at zero current, reverse the pulse, and measure the limits. The paper is intentionally strict because the project is still pre-measurement. Its novelty is the architecture and falsifiable proof plan; performance claims are deferred until data exist.

\section{Results}

\subsection{A fixed cartridge turns actuation into keeper overlap}

The locked architecture separates the magnetic cartridge from the moving carriers (Fig.~\ref{fig:cartridge}). The cartridge contains the Alnico pulse element, the NdFeB bias element, and the top and bottom steel pole plates. The moving structure contributes steel keepers only: two fork prongs from one side and a center tongue from the opposite side. The useful magnetic path is therefore local to the overlap between the fixed pole plates and the moving steel keepers. This makes the one-axis proof inspectable because the visible width change and the hidden magnetic variable are linked by one measurable dimension: keeper overlap.

\subsection{The lane layout removes collision before fabrication polish}

The one-axis layer uses a comb/fork topology (Fig.~\ref{fig:lane}). The center tongue enters between the Alnico and NdFeB rods, while the fork prongs pass outside the pair. The moving steel pieces therefore interdigitate rather than collide. This geometry is a prerequisite for meaningful actuation testing: if the carriers collide, any later force or current measurement would only describe a packaging failure. The lane figure therefore serves as an engineering gate before committing to a monolithic two-axis cell.

\subsection{The dimensional lock creates a falsifiable binary proof}

The current dimensional correction uses 1.00 inch keeper inserts rather than 1-1/8 inch inserts. With 1.25 inch square pole plates, the one-axis proof targets a 3.0 inch expanded/off width and a 1.5 inch contracted/on width, corresponding to a 0.75 inch side stroke. The off-state overlap is approximately 0.125 inch and the on-state overlap is approximately 0.875 inch (Fig.~\ref{fig:overlap}). These numbers are design targets, not measured performance. Their value is that they make the first physical test falsifiable: a synchronized record can show width, pulse polarity, current, hold at zero drive, release after reverse pulse, and coil temperature.

\section{Discussion}

The strongest version of \fluxcell{} is not a generic magnetic actuator paper. It is a paper about pulse-programmed mechanical memory. The state variable is not merely magnetic polarity; it is a visible mechanical configuration coupled to magnetic overlap and held after the electrical pulse ends. If the one-axis proof records clean switching, zero-current hold, reverse-pulse release, bounded heating, and repeated cycles, the work can move from design protocol to actuator evidence.

The source boundary matters. This manuscript does not claim force density, efficiency, safety, lifetime, or reliable two-axis behavior. It claims that the current design has become concrete enough to test and that the proof has been reduced to a small set of measurements. That reduction is the paper's present contribution. It makes the next experiment difficult to hand-wave: either the geometry moves and holds under a measured pulse, or the data identify the dominant failure mode.

For R\&D in physical experiences, the compelling artifact would be a small surface that changes contour, holds while electrically quiet, and returns on command. That future demonstrator would be human-readable because the motion, latch, and reset are visible. The current paper does not claim that demonstrator exists. It defines the cell-level experiment that must pass before that story is credible.

\section{Materials and Methods}

\subsection{One-axis proof geometry}

The proof uses a fixed center EPM cartridge with two 1.25 inch square pole plates made from 0.25 inch by 1.25 inch 1018 steel rectangle bar cut to 1.25 inch length. The magnetic elements are one 0.250 inch diameter by 0.625 inch long Alnico 5 rod and one 1/4 inch diameter by 5/8 inch long NdFeB rod. The moving keepers are two A36 fork prong inserts, each 1/8 inch by 1/2 inch by 1.00 inch, and one 1018 center tongue insert, 1/4 inch by 1/2 inch by 1.00 inch.

\subsection{Electrical pulse protocol}

The Alnico coil is insulated with Kapton, wound with 30 AWG magnet wire, and connected to an H-bridge driver from a current-limited bench supply. The first test uses short bidirectional pulses separated by zero-drive intervals. For each pulse, the record should include polarity, pulse duration, current limit, observed width, hold state after zero drive, release state after reverse pulse, and a coil temperature note.

\subsection{Acceptance boundary}

The first proof succeeds only if the one-axis assembly visibly changes width, holds a state after current returns to zero, releases or reverses under the opposite pulse, and stays within a temperature range safe enough for continued bench testing. A partial result remains useful if it identifies the dominant failure mode: weak magnetic force, high friction, carrier twist, thermal limit, or poor release margin.
